# AIGC 群島

室內設計系碩士班《人工智慧生成內容應用》的 3D 課程網站。學生以第三人稱角色在 18 座課程島嶼之間行走，島嶼依週次以木橋相連；走上島嶼開啟該週單元，完成檢核清單建村莊、繳交作業升級城市，擲骰收集五種 AI 資源，擲到 7 時要回答 AI 幻覺思辨題驅散迷霧。

## 操作

- 電腦：WASD／方向鍵移動、Shift 奔跑、空白鍵跳、拖曳轉視角、滾輪縮放、E 開啟單元
- 手機：左下搖桿移動、拖曳畫面轉視角
- 「週次地圖」可直接前往或開啟任一週

## 檔案

| 檔案 | 內容 |
| --- | --- |
| `index.html` | 頁面與 HUD |
| `css/style.css` | 樣式 |
| `js/data.js` | 課程內容：18 週單元、資源、思辨題、知識卡（修改課程只需改這裡） |
| `js/world.js` | 3D 群島世界（three.js r128） |
| `js/game.js` | 遊戲規則、HUD 與存檔 |

## 本機預覽

```bash
python -m http.server 8765
```

然後開啟 http://localhost:8765 。學生進度存在各自瀏覽器的 localStorage，可在「課程總覽」匯出進度碼。
